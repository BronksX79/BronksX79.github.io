Every project above has a polished write-up. This is the unfiltered version — wrong turns, wasted afternoons, and the one time it was just a Save button.

JUL 2026

Building the Blunders page generated its own blunder

Added this very page, then spent an hour convinced the new nav link simply wouldn't appear anywhere — cache clears, incognito, curl checks, the works. Turned out the server directory had recently been replaced with a fresh git clone, and the running Caddy container was still bind-mounted to the old, deleted copy of it — invisible from the host, invisible from git, only visible by comparing inode numbers directly. Fixed by force-recreating the container so Docker re-established the mount. Then, cleaning up: a wildcard sed command meant to add "Blunders" to the nav ran against every HTML file in the folder — including the brand-new Blunders page itself, which already had its own nav link. Ended up with two.

MusicBrainz Picard couldn't reach Tailscale (because I forgot to press Save)

Spent half a day convinced I'd broken something in the Tailscale ACL — rewrote the rule more times than I want to admit, restarted services, burned a stack of AI tokens reasoning through syntax that was never the problem. The rule was fine the entire time. I'd typed the four numbers, looked at it, and moved on — without ever clicking the actual Save button sitting right there in the ACL editor. Nothing had taken effect. Not once.
