The Workflow

From conversation to knowledge base

The goal isn't to preserve every AI conversation verbatim — it's to keep the decisions, reasoning, and lessons that will matter later, and make them retrievable.

1

Engineering work or cloud-AI session

Local build work, troubleshooting, or a session with ChatGPT, Claude, Google AI Mode, AI Studio, or Grok — whichever tool fits the task and is available.

2

Knowledge-extraction prompt

A repeatable prompt turns the raw session into a structured record instead of leaving the reasoning trapped in a chat history.

3

Summary, knowledge map, engineering log

An Engineering Session Summary and Knowledge Map are produced every time; a full Engineering Log is added when the session involved substantial reasoning.

4

Human review

Nothing an AI produced becomes a fact without verification. Confirmed facts, hypotheses, and future plans stay clearly separated.

5

Bronks Labs knowledge base

Reviewed material is ingested into AnythingLLM, ready for local RAG retrieval.

6

Better-informed future work

Retrieval feeds back into the next engineering decision or the next chapter of Aurelia — human and AI, working from the same verified record.

Deterministic scripts handle the predictable parts of this pipeline — like the batch workflow that syncs repositories to the PC and server. AI is reserved for the parts that genuinely need interpretation.

The Stack

Software and working method

Each piece has a defined, current role — not a wishlist of tools. Full detail for each lives in the repo's docs/software/ folder.

Runtime

Ollama

Serves local language and embedding models to both AnythingLLM and Hermes Desktop. Currently configured with an 8K active context window — some installed model names reference larger windows, but that's the model name, not the runtime setting.

Knowledge base & RAG

AnythingLLM

The local knowledge-base and retrieval layer, using nomic-embed-text for embeddings. Currently being rebuilt workspace-by-workspace from surviving source material after a prior vector-data loss — the hard copies were never lost.

Under evaluation

Hermes Desktop

An early-stage file-work experiment, not a production automation system. It's demonstrated useful file-oriented work, but has no broader operational role until it has a narrow, pre-approved purpose and an enforceable safety boundary.

Inventory

Models

Twelve local models spanning Gemma 3/4, Qwen3, and several fine-tuned variants, evaluated by demonstrated usefulness in a specific workflow rather than benchmark reputation. Gemma 3 12B and Gemma 4 12B currently drive the Aurelia paired-draft writing process.

Hybrid workflow

Cloud AI Workflow

Local AI runs alongside web tools — ChatGPT, Claude, Google AI Mode, AI Studio, Grok — routed pragmatically by task and availability, with cloud output always treated as input for review, not verified fact.

Deferred & retained

Tool Evaluations

Supporting tools like Fooocus, Pinokio, Voicebox, and ACE Step are tracked here even while inactive, so real experiments aren't quietly forgotten or overstated as production-ready.

Current snapshot

Last verified 2 August 2026 — full detail in docs/STATUS.md

Operating position

  • Local AI runs on the Windows 11 workstation through Ollama, 8K context.
  • AnythingLLM is the active knowledge-base and RAG layer.
  • Deterministic automation is preferred over AI-mediated control wherever possible.
  • Aurelia uses local AI as a drafting collaborator, with human review before anything is kept.

Active work

  • Awaiting a server RAM upgrade, timed with a planned shutdown.
  • Backup hardware — HDD, enclosure, powered USB hub — staged for deployment.
  • Backup-and-restore verification still needed once deployed.
  • Repository documentation migrating from a minimal README to full docs.

Documentation as an engineering tool, not decoration

  • Preserve why a decision was made, not only what changed.
  • Keep confirmed facts separate from hypotheses and future plans.
  • Record mistakes when they teach a reusable lesson.
  • Prefer a small number of well-linked documents over unstructured notes.
  • Never let an AI-generated explanation become a fact without verification.
